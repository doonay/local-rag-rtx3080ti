# Local RAG для RTX 3080 Ti

## Локальная Windows RAG-система для загрузки PDF/TXT/MD, поиска по документам и генерации ответа.
При первом запуске скрипт [start-local.bat](start-local.bat) автоматически:
- создаст изолированное Python-окружение `.venv-local`;
- установит PyTorch с CUDA 12.8 и остальные зависимости;
- скачает официальную переносимую Windows-сборку llama.cpp;
- скачает `Qwen3-8B-Q4_K_M.gguf`;
- запустит Qwen3 на GPU, локальное API и откроет браузер.

Первый запуск скачивает несколько гигабайт и может быть долгим.
Последующие запуски не требуют установки и Web UI запускается мгновенно.
Для остановки используйте [stop-local.bat](stop-local.bat).
Логи находятся в `.local/logs`, индекс документов — в `.local/qdrant`.

Нативный режим использует встроенный Qdrant Local, поэтому не требует отдельного сервера базы данных.
Для ручной предварительной установки можно запустить [setup-local.bat](setup-local.bat).

Пайплайн запроса:
```text
браузер → локальный API → BGE-M3 dense+sparse → Qdrant Local → Qwen3 Reranker 0.6B → Qwen3 8B GGUF
                         CPU                            CPU          GPU                  GPU (llama.cpp)
```

## Почему такой GPU-профиль

`Qwen3-8B-Q4_K_M.gguf` запускается через llama.cpp на GPU. `Qwen3-Reranker-0.6B` также использует GPU, а BGE-M3 и встроенный Qdrant Local работают на CPU. Такой профиль рассчитан на 12 ГБ VRAM и не требует отдельных серверов.

## Требования
- Windows 10;
- актуальный NVIDIA-драйвер;
- 32 ГБ RAM желательно, 24 ГБ — практический минимум;
- 15 ГБ свободного места на установку и кэши моделей.

Проверенная карта в этой системе: RTX 3080 Ti, 12 288 MiB, compute capability 8.6, драйвер 591.74.

Web UI: <http://localhost:8000>, Swagger: <http://localhost:8000/docs>. Qdrant работает внутри приложения и не открывает отдельный порт или dashboard.
