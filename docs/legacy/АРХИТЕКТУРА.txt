API - готовый контейнер с фастапи на борту, который я потом отдельно настраиваю с CI/CD
Два разных пайплайна:
Ingestion: API загрузка документации -> PDF -> Parser -> Cleaner -> Chunker -> Embedder -> Qdrant
и
Query: API запрос пользователя -> Embedder -> Qdrant -> Reranker -> vLLM -> API ответ пользователю

-----

embedder - Есть готовые контейнеры с sentence-transformers. Например SentenceTransformer("BAAI/bge-m3")
Контейнер: Python - sentence-transformers - bge-m3
API запрос: POST /embed {"texts": ["chunk 1", "chunk 2", "chunk 3"]}
API ответ: {"embeddings": [[0.123,0.456], [0.234,0.567]]}

-------------
qdrant - Есть готовый контейнер qdrant/qdrant
В Qdrant хранить не только vector а, но еже и metadata: {"text": "текст чанка","source": "manual.pdf","page": 12,"document_id": "123","created": "2026-07-10"}
Потом это позволит делать: фильтр по документам; удаление документов; цитирование источников.

-------------
reranker - Это контейнер, внутри которого одна модель. Например BAAI/bge-reranker-v2-m3 или Qwen3-Reranker
У него API: POST /rerank {query, documents[]} Ответ: [0.98,0.92,0.74,...]
FastAPI берет Top-5 и отправляет их в vLLM. Qdrant - Top-50 - Reranker - Top-5 - vLLM

-------------
vLLM + Qwen2.5-14B-Instruct-AWQ - Поднимается официальный контейнер.
Он уже предоставляет OpenAI-совместимый API: POST /v1/chat/completions или другую AWQ/GPTQ модель.
Для RTX 3080 Ti 12GB это реалистичнее.

Полный пайплайн запроса (Query)
# api/routes/ask.py
@app.post("/ask")
async def ask(request: QueryRequest):
    # 1. Эмбеддинг вопроса
    query_embedding = await embed_text(request.question)
    
    # 2. Поиск в Qdrant (Top-50)
    search_results = await qdrant_search(
        vector=query_embedding,
        limit=50,
        filter={"document_id": request.document_id} if request.document_id else None
    )
    
    # 3. Ранжирование (Reranker)
    reranked = await rerank(
        query=request.question,
        documents=[r.payload["text"] for r in search_results]
    )
    
    # 4. Берем Top-5
    top_chunks = reranked[:5]
    
    # 5. Формируем промпт
    context = "\n\n".join([chunk.text for chunk in top_chunks])
    prompt = f"""
    Используя контекст ниже, ответь на вопрос.
    
    Контекст:
    {context}
    
    Вопрос: {request.question}
    
    Ответ:
    """
    
    # 6. Отправляем в vLLM
    answer = await llm_generate(prompt)
    
    # 7. Возвращаем ответ с источниками
    return {
        "answer": answer,
        "sources": [
            {
                "text": chunk.text,
                "source": chunk.metadata["source"],
                "page": chunk.metadata.get("page")
            }
            for chunk in top_chunks
        ]
    }

💡 Дополнительные советы
Мониторинг: Добавьте Prometheus метрики для каждого сервиса (латентность, количество запросов, ошибки)
Graceful degradation: Если vLLM упал, API должен возвращать "Сервис временно недоступен" без падения всего приложения
Кэширование: Частые вопросы можно кэшировать в Redis (эмбеддинг + ответ)
Очереди: При большой нагрузке на ingestion, используйте Celery или Redis Queue, чтобы не блокировать API
